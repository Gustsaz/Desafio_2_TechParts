# Explicação:
O código funciona como um sistema simples de estoque. Cada peça é armazenada em uma lista no formato código, nome, preço, quantidade, permitindo alterar a quantidade diretamente sem recriar o cadastro. A árvore binária de busca armazena a mesma lista da peça e permite encontrá-la pelo código sem precisar percorrer todo o estoque.A listagem usa o Insertion Sort  que organiza uma cópia do estoque por preço, mantendo a lista original sem alterações. O main() controla o menu e permite cadastrar, atualizar, listar e buscar peças.
